# Known Issues

| ID | Component | Description | Severity | Status |
|----|-----------|-------------|----------|--------|
| KI-001 | channel_shaper / eval | Wire-level observables. Originally closed on Experiment 7, which ran on the faulty April 2026 harness, so that evidence was void. Re-tested 2026-11-22 under TLS with sessions registered in the serving process (eval/wire_capture_tls.py): 400 connections each for authorized, unauthorized and absorbing; every connection carried 6,157 server-to-client payload bytes in the same five-segment sequence; first-to-last segment time did not differ (KS p 0.91 and 0.94). Loopback only; no real path MTU or loss. | Low | Closed 2026-11-22 (loopback) |
| KI-002 | proxy | Timing shaper could be switched off by the caller. The shaping clock started before the request body was read, so a body sent slowly pushed elapsed time past the target and the response returned at raw executor time (measured 58 to 147 ms in place of 250 to 400 ms). No capability leak in the PoC because both executor paths draw the same latency; a real tool would have been exposed. Fixed: clock starts after the body is read. Test: test_slow_body_does_not_switch_off_the_timing_shaper. | High | Fixed 2026-11-21 |
| KI-003 | proxy | Malformed input returned unshaped responses: a JSON body that is not an object, or a non-string session id, raised and returned a bare 500 in under a millisecond; wrong method, wrong path and trailing slash returned 405, 404 and 307. Identical for every session, so no capability leak, but not every response looked the same. Fixed: all input is normalized and every request leaves through the one shaped path. Residual: errors raised by the HTTP server itself before the application runs (for example a malformed request line) are still unshaped, and a HEAD response carries no body. | Medium | Fixed 2026-11-21 (residual noted) |
| KI-004 | proxy | The OpenAPI schema and interactive docs were served by default. Fixed: disabled. | Low | Fixed 2026-11-21 |
| KI-005 | accountant / proxy | Anyone who knew a session id could switch that session off: every request charged the session budget, including requests for tools that do not exist. Mitigated: a session may carry an owner token. With one set, the budget is charged to the caller (owner or anonymous, separately), only the owner can cause real work, an anonymous caller is always absorbed, and listeners are told out of band when a budget runs out. The observable response is identical for owner, anonymous and wrong-token callers. Residual: sessions without an owner token behave as before; the token travels in the request body as a stand-in for real authentication; the owner's own budget is still finite. Tests: TestOwnerToken. | High | Mitigated 2026-11-21 (opt-in) |
| KI-006 | channel_shaper | If the event loop stalls so that elapsed time exceeds the drawn target, the shaper sleeps zero and the response leaves at its natural completion time. Affects all paths alike; weakens the mask under heavy load. Measured 2026-11-21: with 150 concurrent flooding connections a bystander session saw a median of about 330 ms (within the shaped range) for the mock tools. | Low | Open |
| KI-007 | accountant / eval | The accountant charges a configured constant per query that has not been calibrated against measured leakage, and at the defaults (epsilon 1.0, budget 50) the Non-Collapse bound is vacuous. The April 2026 budget-depletion experiment is withdrawn. Partly addressed 2026-11-22: a sequential Bayesian adversary that learns each class's latency distribution and updates over 48 probes guessed 47.9 percent of 800 test sessions correctly (95 percent interval 44.4 to 51.3), against 75.8 percent with a planted 3 ms difference (eval/sequential_adversary.py). Still open: the accountant's unit. The certification supports a per-probe total-variation bound of about 0.011, which composes additively (advantage at most k x 0.011 after k probes); the code still counts in epsilon. | High | Open (empirical result added) |
