# Known Issues

| ID | Component | Description | Severity | Status |
|----|-----------|-------------|----------|--------|
| KI-001 | channel_shaper / eval | TCP inter-segment timing. Previously closed on Experiment 7 sub-test 3 (KS p=0.693, n=50 per path). Experiment 7 ran on the faulty April 2026 harness (see docs/EMPIRICAL_FINDINGS.md), so that evidence is void. Needs a re-run under the in-process harness. | Low | Reopened 2026-11-21 |
| KI-002 | proxy | Timing shaper could be switched off by the caller. The shaping clock started before the request body was read, so a body sent slowly pushed elapsed time past the target and the response returned at raw executor time (measured 58 to 147 ms in place of 250 to 400 ms). No capability leak in the PoC because both executor paths draw the same latency; a real tool would have been exposed. Fixed: clock starts after the body is read. Test: test_slow_body_does_not_switch_off_the_timing_shaper. | High | Fixed 2026-11-21 |
| KI-003 | proxy | Malformed input returned unshaped responses: a JSON body that is not an object, or a non-string session id, raised and returned a bare 500 in under a millisecond; wrong method, wrong path and trailing slash returned 405, 404 and 307. Identical for every session, so no capability leak, but not every response looked the same. Fixed: all input is normalized and every request leaves through the one shaped path. Residual: errors raised by the HTTP server itself before the application runs (for example a malformed request line) are still unshaped, and a HEAD response carries no body. | Medium | Fixed 2026-11-21 (residual noted) |
| KI-004 | proxy | The OpenAPI schema and interactive docs were served by default. Fixed: disabled. | Low | Fixed 2026-11-21 |
| KI-005 | accountant / proxy | Anyone who knows a session id can switch that session off. Every request charges the session budget, including requests for tools that do not exist, and the charge is per session, not per tool. 60 requests for a non-existent tool pushed a default-budget session into permanent absorption. Design issue; related to the budget-exhaustion limit in the paper. | High | Open |
| KI-006 | channel_shaper | If the event loop stalls so that elapsed time exceeds the drawn target, the shaper sleeps zero and the response leaves at its natural completion time. Affects all paths alike; weakens the mask under heavy load. | Low | Open |
| KI-007 | accountant / eval | The accountant charges a configured constant per query that has not been calibrated against measured leakage, and at the defaults (epsilon 1.0, budget 50) the Non-Collapse bound is vacuous. The April 2026 budget-depletion experiment is withdrawn (faulty harness; adversary with a one-sided likelihood ratio). Empirical non-collapse is open. | High | Open |
